# Navigation architecture

The intended mobile experience uses five primary tabs.

| Tab | Purpose |
|---|---|
| Chats | Human conversations and service threads |
| People | Verified contacts, groups, households, and organizations |
| Apps | Modular DigiCom-enabled tools and linked services |
| Activity | Notices, requests, transactions, service updates, and receipts |
| Profile | Identity, permissions, MyGene controls, settings, and linked services |

## Service-source clarity

Messages and events must show whether they came from a user, another person, organization representative, application, regulated partner, system process, or MyGene.

Incomplete or failed actions must not be presented as successful.
