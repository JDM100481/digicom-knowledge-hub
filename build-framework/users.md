# U: Users

## Objective

Understand users in their actual context, define the minimum useful journey, and decide which needs should be served through reusable DigiCom capabilities.

## User understanding

Define goals, constraints, current workarounds, language, literacy, accessibility, devices, connectivity, trust, personally controlled actions, failure points, and the smallest experience that creates meaningful value.

## Capability test

For every required capability, classify it as:

| Classification | Meaning |
|---|---|
| Reuse | Existing shared capability is suitable |
| Extend | A compatible addition is needed |
| Create shared | A new reusable capability is justified |
| Product-specific | It properly belongs to one product |
| Partner-provided | An external provider must supply it |
| Controlled | Separate approval and higher assurance are required |

## Gate principle

Proceed only when the user journey is understood, unnecessary duplication is removed, responsibilities and data boundaries are visible, controlled capabilities are separated, and the minimum solution is plausible.
