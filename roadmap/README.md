# Roadmap and releases

DigiCom documentation will mature in controlled releases.

## Foundation

* protocol overview and principles;
* ecosystem boundaries;
* BUILD Framework;
* shared terminology;
* initial governance and conformance model.

## Specification

* protocol actors and trust boundaries;
* service-thread lifecycle;
* identity, consent, and authorization requirements;
* information-exchange contracts;
* audit and event models;
* conformance profiles.

## Reference implementation

* schemas and API definitions;
* SDK guidance;
* example integrations;
* automated conformance tests;
* pilot implementation guides.

## Release policy

Published specifications will carry a version and status such as draft, candidate, approved, or deprecated. Breaking changes will include migration guidance.
