## Next documentation layers

### Protocol specification

* actors and trust boundaries;
* identity, roles, permissions, and consent profiles;
* service-thread and action contracts;
* information-exchange schemas;
* security, evidence, and incident requirements;
* conformance profiles and test evidence.

### Reference implementation

* API definitions and schemas;
* SDK guidance;
* example integrations;
* test fixtures;
* reference service threads;
* automated conformance tests.

### Pilot documentation

Pilot documentation will be produced only after a product passes the required BUILD gates and receives explicit operational authorization.

## Release policy

Published specifications will identify version, status, scope, and effect. Breaking changes require change control and migration guidance.
