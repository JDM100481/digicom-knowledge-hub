# Ecosystem architecture

The DigiCom Protocol uses six layers.

## Constitutional layer

Defines authority, stewardship, ownership principles, reserved matters, venture separation, and amendment rules.

## Protocol layer

Defines shared roles, contracts, trust, information exchange, conformance, and controlled capabilities.

## Shared capability layer

Supports reusable identity, permissions, messaging, actions, notifications, evidence, discovery, wallet integration, eSIM integration, local assistance through MyGene, and other common functions.

## Product layer

Contains standalone applications that solve defined problems and adopt only the capabilities required for their authorized scope.

## Common experience layer

Provides myCHAT as the intended modular platform through which people communicate with and use DigiCom-enabled tools.

## Partner layer

Includes government entities, financial institutions, telecommunications providers, enterprises, community organizations, and other authorized parties supplying services, authority, distribution, data, or regulated capabilities.
